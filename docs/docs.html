Docs

Ngintip is an intercepting HTTP(S) proxy: a Rust backend (tokio, hyper, rustls, rcgen) in a Tauri 2 window. Start with Install, then First run. Everything after that is one page per tool.

The app also carries a Guide page with every keyboard shortcut, which this site does not try to duplicate.

Performance

What one real engagement costs on disk: 41,692 requests, 123 hosts, nine days, one 412 MB file.

Getting started

Install

Download a native build of Ngintip for macOS, Windows or Linux, or build it from source.

First run and the CA

Point a client at the proxy on 127.0.0.1:8080, trust the generated root CA, and set your scope.

Built-in browser

Launch a Chromium already wired to the proxy, with its own profile, downloaded if you do not have one.

Capture

History

The capture table: scope filtering, full-text body search, sitemap, viewers and export.

Intercept

Hold a request, a response or a WebSocket frame, edit it, then forward or drop it.

Replay

Repeater

Resend and edit requests in tabs, with bodies that keep the bytes you typed, and capture images.

Intruder

Sniper, battering ram, pitchfork and cluster bomb, with a wordlist per position.

Organizer

Collections of saved requests, kept with the project and re-runnable later.

Automation

Rules and Passive Scan

Regex match and replace rules, and passive rules that read captured traffic.

Extensions

Python hooks: change traffic on the wire, decode a body for reading, or re-encode it on send.

MCP server

Expose the capture to an AI client over a local-only MCP server.

Reference

Decoder and Comparer

Decoder for Base64, URL, entities, hex, JWT and hashes, plus a word or byte comparer.

Projects and Footprint

One SQLite file per engagement, and the three decisions behind the footprint.

About

Who built Ngintip, and the reason it exists: one more option, lighter and faster than what was around.
