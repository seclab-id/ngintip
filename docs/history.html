History

Everything that crossed the proxy, in one table that does not slow down as it fills.

The table

Rows are virtualized, so tens of thousands of flows scroll at the same speed as ten. Each row takes a note and a colour, and both are saved with the project. Columns are resizable, and the sort order you choose is remembered per project.

  • Scope filter hides everything outside the hosts you declared.
  • Search runs over decoded request and response bodies through SQLite FTS5, not just URLs.
  • Sitemap folds the same capture into a host and path tree.
  • Export writes HAR, or the XML that other proxies import.

Reading a message

Raw shows the bytes as they crossed the wire. Pretty re-indents a JSON or markup body for reading, without rewriting it: an escape like \u0063, an escaped solidus or a duplicate key stays exactly as the target sent it. Preview renders an HTML response in a sandboxed frame, and a binary body gets a hex dump instead of mojibake.

Rows that never got an answer

A request whose answer never arrived is recorded as exactly that, not as an error. Ngintip separates "the client hung up" from "the target failed", because only one of those belongs in a report. The record says which, in words, when you open it.
