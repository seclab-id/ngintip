Install

Download a build, or make one. Both take a couple of minutes.

Download

Every platform gets a native installer. Sizes are the actual files on the v0.3.0 release page:

Installer size per platform, release v0.3.0
PlatformFileSize
macOS, Intel and Apple Silicon.dmg, universal12.7 MB
Windows.exe installer5.2 MB
Windows.msi7.3 MB
Debian, Ubuntu.deb6.9 MB
Fedora, RHEL.rpm6.9 MB
Linux, portable.AppImage81.1 MB carries its own GTK and WebKit

Each release ships SHA256SUMS.txt; check your download against it before installing. The macOS build is signed with a Developer ID certificate and notarized, so it opens without a Gatekeeper detour.

Build from source

git clone https://github.com/seclab-id/ngintip
cd ngintip
./run.sh          # dev mode
./run.sh build    # .app / .dmg / .deb / .AppImage

Needs Rust (stable) and Node.js 22.12 or newer. Windows uses run.ps1. On Linux also libwebkit2gtk-4.1-dev, libayatana-appindicator3-dev and librsvg2-dev.

Tests are cargo test in src-tauri (unit and end-to-end, with a real proxy in front of a local origin) and npm test at the root. CI runs both on Linux, macOS and Windows.
