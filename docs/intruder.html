Intruder

The same request, many times, with the parts you marked replaced.

Attack types

  • Sniper walks one wordlist through one position at a time.
  • Battering ram puts the same payload in every position at once.
  • Pitchfork steps several wordlists in parallel, one entry each per request.
  • Cluster bomb runs every combination of every wordlist.

Each position gets its own wordlist, so a user list and a password list do not have to be the same length or shape.

Results

Results land in a table you can sort and filter by status, length and time, which is usually how an interesting row announces itself. Runs are saved with the project rather than lost when the window closes, and any row can be sent on to the Repeater to be worked by hand.
