First run and the CA

Point a client at the proxy, trust the CA, set your scope. Then everything else works.

The listener

The proxy listens on 127.0.0.1:8080. Set that as the HTTP proxy in your browser, your phone's Wi-Fi settings, or whatever client you are testing. Nothing is exposed beyond localhost unless you say so.

For clients that cannot be pointed at a proxy, invisible mode accepts direct connections and routes them by the Host header or the TLS SNI. An upstream HTTP or SOCKS5 proxy can sit in front, and the listener itself can require Basic auth.

The CA

To read HTTPS, Ngintip mints a certificate per host as you browse, signed by a root CA it generates on your machine the first time it starts. Here is exactly what that root is:

Root CA details
Common nameNgintip Proxy CA
OrganizationNgintip, OU seclab.id
KeyECDSA P-256, signed ecdsa-with-SHA256
Validity10 years from the day it is generated
Filesca.pem and ca.key in the app's data directory
Per-host certificatesCN is the host, valid 1 year, minted on demand and cached

That is the name you will look for in Keychain Access, certmgr.msc, or your browser's certificate manager: Ngintip Proxy CA. Settings shows the same details, the fingerprint, and copy-paste steps for macOS, Windows, Linux, Firefox, Android and iOS.

The quickest way to install it: browse to http://127.0.0.1:8080/ through the proxy, and it serves the certificate for download.

The private key is generated on your machine and never leaves it. Trusting this root means that machine will accept any certificate Ngintip mints, so install it on the devices you are testing with and nowhere else, and remove it when the engagement ends. Settings can regenerate the root, which invalidates every certificate signed by the old one.

You can skip trusting it entirely by using the built-in browser, which runs in a throwaway profile that ignores certificate errors. That is the fastest path for a quick look at one target.

Scope

Scope is the list of hosts you are allowed to touch, and the rest of the app follows it. It filters History, decides what the passive rules read, and gates extensions: an out-of-scope host passes through untouched and unanalyzed.

Set it before you start. It is the difference between a capture you can hand over and one you have to clean up.
